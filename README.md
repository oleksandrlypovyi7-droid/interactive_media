У проєкті реалізовано покадрову анімацію персонажа у форматі програмно згенерованих графічних буферів 
розміром 96×96 пікселів для кожного кадру без використання зовнішніх зображень. 

Додано три цикли анімації з різною частотою кадрів:
1. стояння (4 FPS);
2. ходьба (11 FPS);
3. біг (15 FPS).

Керування:
+ `1`, `2`, `3` - перемикання анімацій;
+ слайдер - зміна масштабу (0.5x–2.5x);
+ Кнопка `Flip` або клавіша `F` - горизонтальне віддзеркалення. 

Можна покращити:
1. додавши анімацію стрибка з фізикою гравітації;
2. плавний рух персонажа по сцені та перевірку зіткнень із перешкодами; 
3. звукові ефекти кроків.

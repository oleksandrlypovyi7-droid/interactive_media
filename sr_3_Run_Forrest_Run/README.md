У грі вже працює рух гравця перетягуванням із просторовим порогом та клавішами, збір монет із коротким звуковим сигналом через Web Audio API, нарахування очок. Червоний ворог безперервно переслідує гравця зі стартовою швидкістю 120 px/сек і прискорюється на 10 px/сек за кожні 5 очок. При зіткненні з ворогом з'являється екран Game Over з можливістю швидкого перезапуску.

Далі варто додати:
1. збереження найкращого рекорду та кнопку ввімкнення/вимкнення звуку;
2. додавання бафів/дебафів в залежності від "з'їдених' монет;
3. адаптивне масштабування полотна під менші екрани.

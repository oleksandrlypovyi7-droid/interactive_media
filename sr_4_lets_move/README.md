У проєкті реалізовано покадрову анімацію персонажа-чоловічка через програмно згенерований спрайтшіт (p5.Graphics, кадри 36×40 px, по 6 кадрів на стан) без зовнішніх файлів.

Додано три анімації з різними FPS та хітбоксами під кожну позу:
1. стояти (4 FPS);
2. крокування (11 FPS);
3. біг (15 FPS).

Керування:
+ 1, 2, 3 — перемикання анімацій;
+ стрілки або WASD — рух по сцені;
+ слайдер — масштаб (1x–4.5x) і розмір хітбоксу;
+ кнопка Flip або клавіша F — віддзеркалення по осі X.

Можна покращити:
1. додати стрибок із гравітацією;
2. додати колізії з перешкодами;
3. додати звук кроків.
